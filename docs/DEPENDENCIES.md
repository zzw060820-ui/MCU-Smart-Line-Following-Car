# 固件外部依赖与权利说明

发布副本保留 god.c 和 KGOD.uvproj，未复制以下原始第三方头文件：

| 依赖 | 原用途 | 本机补齐方式 |
| --- | --- | --- |
| uart.h | UART 初始化、中断、printf 重定向；XTAL=11059200、9600 bps | 从有使用权限的原教学板材料取得，放在本机 firmware/Ant/ 或设置本地 include 路径 |
| Boebot.h | delay_nus、delay_nms | 从有使用权限的教学板材料取得；源码 include 使用 BoeBot.h，Windows 大小写不敏感 |
| AT89X52.H | 8051 寄存器及位定义，被 uart.h 引用 | 使用合法安装的 Keil 提供的匹配头文件，或经授权的原始版本 |

原本地源码仍持有这些文件，本次没有删除它们。为避免未知授权材料上传，.gitignore 明确排除这些文件名。缺失它们时固件不能开箱编译；自行取得兼容头文件后，还需验证延时、引脚、晶振和串口设置。

Keil/C51、USBasp/ProgISP、驱动和课程教材均不随仓库分发。Python 模块只依赖标准库。不得将整个工程套用新许可证来覆盖第三方版权；以后决定开源许可时应先确认自有代码和合作贡献者授权。
