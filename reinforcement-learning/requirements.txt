# 本项目**不需要任何第三方依赖**。
#
# 设计目标之一就是"零安装即可跑"：
#   - 训练、评估、导出全部只用 Python 标准库（random / math / json / csv / argparse）
#   - 测试用标准库自带的 unittest，不需要 pytest
#   - 不需要 numpy、不需要 GPU、不需要任何深度学习框架
#
# 状态空间只有 16 x 6 = 96 个 Q 值，用纯 Python 的嵌套 list 完全够用，
# 引入 numpy 只会增加安装门槛而没有收益。
#
# 唯一的环境要求：Python >= 3.8（实测环境为 3.12.10）
#
# 如果确实想用 pytest 跑测试（可选，非必需）：
# pytest>=7.0
