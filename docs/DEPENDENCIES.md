# 固件依赖与来源

2026-10-29 更新候选按完整工程同步，保留 FIELD-1 实际使用的三个头文件，原字节与原声明均不变。

| 文件 | 用途与来源 |
| --- | --- |
| `firmware/Ant/uart.h` | 原项目所附串口实现，XTAL=11059200、9600 bps，含 UART 中断和 printf 重定向 |
| `firmware/Ant/Boebot.h` | 原项目所附 delay_nus/delay_nms，与现有控制参数配套 |
| `firmware/Ant/AT89X52.H` | 原项目所附寄存器定义，保留 Keil 1988–2002 版权声明 |

三个文件与原 Ant 的对应文件一致。此前发布将其作为外部依赖排除，导致克隆后不能完整编译；本次移除对应忽略项以保留必要依赖。公开收录涉及第三方材料，上传前须单独确认这一项；本次未发现新的再分发许可文本，不替换、删改原声明或添加覆盖这些文件的新许可证。

还需合法安装 Keil C51：stdio.h、标准运行库、默认启动代码等由工具链提供。无需将整个 Keil 安装目录、驱动或下载软件上传。工程没有额外引用项目外的自有 C/汇编/库文件，只有 god.c 参与固件编译。

注意：源码引用 BoeBot.h，实际文件为 Boebot.h；uart.h 引用 AT89X52.h，实际为 AT89X52.H。Windows 通常可解析；本次保持名称和源码不变，不声称在大小写敏感的文件系统上直接可编译。

工程 XML CLOCK=33000000 与 uart.h XTAL=11059200 不一致，本次不调整。工具链路径由使用者的本机安装决定。主机逻辑测试需要 GCC，使用 tests/stubs，不使用 C51 寄存器头文件。
